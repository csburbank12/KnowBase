# Knowledge Fortress Growth Plan

## Goal
Build Knowledge Fortress into a classroom game platform that can compete with products like Gimkit/Blooket by improving retention, multiplayer depth, and teacher outcomes.

## Phase 1 — Product Foundation (Current)
- [x] Secure custom quiz ingestion (sanitization + payload validation)
- [x] Session reporting export (CSV)
- [x] Local progression loops (leaderboard + player profile)
- [x] Local analytics event pipeline + export (for rapid product iteration)

## Phase 2 — Classroom Multiplayer Core
- [ ] Host lobby + join code flow
- [ ] Real-time player sessions with websocket transport
- [ ] Live class leaderboard updates during play
- [ ] Teacher controls: pause, next wave, forced question reveal, kick/ban

## Phase 3 — Content & Replayability
- [ ] Daily/weekly challenges with rotating modifiers
- [ ] Class missions + quest chains
- [ ] Verified question packs by grade/subject standards
- [ ] Question editor with import templates and validation UI

## Phase 4 — Teacher Platform
- [ ] Class rosters and assignment scheduling
- [ ] Post-game mastery analytics by standard/tag
- [ ] Auto-generated intervention groups
- [ ] LMS sync (Google Classroom, Canvas)

## Phase 5 — Growth & Scale
- [ ] Auth + multi-tenant architecture
- [ ] Analytics warehouse + cohort retention dashboards
- [ ] Matchmaking/ranking system for competitive modes
- [ ] Regional infra + caching strategy for low-latency classrooms

## Success Metrics
- D1 / D7 retention
- Average sessions per classroom per week
- Session length and question throughput
- Assignment completion rate
- Teacher NPS and renewal intent
